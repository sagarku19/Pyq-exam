02 — Payments

Cashfree Integration Flow

1️⃣

User clicks "Upgrade to Pro" on pricing page

Frontend calls POST /api/v1/payments/create-order with plan, amount, user details. Backend uses cashfree-pg npm package to call Cashfree's PGCreateOrder API.

2️⃣

Backend creates Cashfree order → returns payment_session_id

Order stored in DB as PENDING. Response returns payment_session_id to frontend. Also stores cf_order_id in your DB for webhook matching.

3️⃣

Frontend opens Cashfree checkout using JS SDK

Load @cashfreepayments/cashfree-js. Call cashfree.checkout({ paymentSessionId }). User pays via UPI / Card / NetBanking. Cashfree redirects to return_url after payment.

4️⃣

User returns to /payment/verify?order_id=xxx

Page calls POST /api/v1/payments/verify with order_id. Backend verifies with Cashfree's PGFetchOrder API. If order_status === "PAID" → upgrade subscription in DB.

5️⃣

Webhook at POST /api/v1/payments/webhook (backup)

Cashfree sends webhook for every payment event. Verify signature with x-webhook-signature header. Update order status as source of truth. Never trust only return_url redirect.
